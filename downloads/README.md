# دریافت Terrain Studio 0.5.0

- `TerrainStudio-0.5.0-Setup.exe`: نصب آفلاین Windows 10/11 x64؛ شامل برنامه و کتابخانه‌ها.
- `TerrainStudio-0.5.0-Source.zip`: سورس همین نسخه و داده نمونه.
- `INSTALL-fa.txt`: راهنمای نصب و رسم محدوده.
- `SHA256.txt`: هش فایل‌های توزیع.
- `TEST-RESULTS.txt`: آزمایش‌های اجراشده و محدودیت‌های اعتبارسنجی.

مرجع ارتفاع، همان DEM یا DSM ورودی است. محدوده روی نقشه رسم می‌شود و همه نواحی جدا با آمار ارتفاع مستقل در یک لایه Shapefile ذخیره می‌شوند.
فایل‌های نصاب نسخه‌های قبلی ممکن است در پوشه باقی مانده باشند؛ برای قابلیت رسم محدوده از 0.5.0 استفاده کنید.
