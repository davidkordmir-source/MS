# Terrain Polygon Export — Offline Windows installer

Download `TerrainPolygon-Setup.exe`, transfer it to the offline Windows computer,
and run it. Windows 10/11 x64 is required. Internet, Python and ArcGIS are not
required on the destination machine. This is the CPU edition; CUDA is not bundled.

`TerrainPolygon-Source.zip` includes the application and packaging source.
`SHA256.txt` contains checksums. See `INSTALL-fa.txt` for Persian instructions and
`TEST-RESULTS.txt` for validation details and limitations. The application payload
was functionally tested in Wine with networking disconnected. Actual Windows
hardware and the complete installer/uninstaller flow have not been validated.
