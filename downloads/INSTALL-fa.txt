Terrain Polygon Export — نسخه آفلاین Windows x64

۱. فایل TerrainPolygon-Setup.exe را با فلش به کامپیوتر ویندوز منتقل کنید.
۲. روی آن دوبارکلیک کنید و مراحل نصب را تا Finish ادامه دهید.
۳. برنامه را از میانبر دسکتاپ یا Start اجرا کنید.

سیستم مقصد به اینترنت، Python و ArcGIS نیاز ندارد.
سیستم موردنیاز: Windows 10 یا 11 نسخه ۶۴ بیتی.
این نسخه از CPU استفاده می‌کند؛ بسته CUDA/GPU ندارد.

ورودی شیپ فایل باید به همراه فایل‌های جانبی SHX، DBF و PRJ باشد.
برای نقطه، شعاع بافر بر حسب متر است. برای پلیگون همان محدوده استفاده می‌شود.
ارتفاع‌ها مطابق واحد عمودی DEM/DSM هستند؛ DSM به‌تنهایی ارتفاع ساختمان از زمین نیست.
خروجی را در یک پوشه قابل نوشتن و با نام جدید ذخیره کنید.
فایل‌های SHP، SHX، DBF، PRJ و CPG خروجی را با هم نگه دارید.

نرم‌افزار با Windows Python و PyInstaller تحت Wine 10 ساخته شده است.
آزمایش روی Windows واقعی و GPU واقعی انجام نشده است.
نسخه حاضر دارای امضای دیجیتال تجاری نیست.
