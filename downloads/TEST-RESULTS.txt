Terrain Studio 0.5.0 — validation on 2026-11-01

43 tests passed, zero failures, on Linux with Python 3.12.
43 tests passed, zero failures, with Windows Python 3.12.10 under Wine 10.
Interaction tests send real wheel events to focused numeric fields and combo
boxes, verify unchanged parameters and scrolling of the containing form, and
verify that keyboard changes still work. Direction changes preserve the entered
height and update the Persian condition sentence.
Live zoom tests use a 2048x2048 raster and actual mouse-drawn AOI. Both the map
and threshold preview read native source-window details after zoom, with the
AOI geometry unchanged. Stale asynchronous results are discarded.
Existing spatial, CRS, unit, NoData, exact clipping, per-feature statistics,
single-raster input and one-dataset output tests remain passing.

The exact float64 OpenCL threshold kernel was compiled and executed with POCL
on a CPU OpenCL device: 12 cases of 8206 values, including NaN, infinities,
signed zero, subnormals and values adjacent to a threshold, matched CPU results.
This is kernel validation on CPU OpenCL, not physical GPU testing.
GPU absence, device failure and CPU-faster auto selection have regression tests.
The packaged Windows OpenCL binding loads successfully; GPU absence uses CPU.

A 42,250,000-pixel synthetic DEM was extracted as one polygon with exact pixel
count and min/max/mean 50 metres using the parallel tile-reading pipeline.
No universal speedup factor is claimed.

The final frozen Windows executable passed extraction, bundled GPU binding /
CPU fallback, animated startup, background GIS import, main-thread widget
creation, branded window icon and renderer readiness checks.
Wine exposed an OpenGL context whose framebuffer was empty; the application
now detects unusable black/white frames and automatically restores CPU drawing.
The corrected packaged map was visually verified.

The x64 installer upgraded the existing test installation, preserved a synthetic
user project file and created the Terrain Studio desktop shortcut. All 1183
installed files match the tested build by SHA256. The installed program passed
startup and extraction checks from outside the source checkout.
The EXE has x64 machine type, file version 0.5.0.0 and embedded icon resources.
New Windows wheels were verified against official PyPI SHA256 metadata.

No native Windows hardware or physical NVIDIA/AMD/Intel GPU was available.
Actual GPU speed and hardware rendering on those cards have not been verified.
Interactive installer pages were not exercised; silent installation/upgrade
was tested. Original user raster data was not supplied. Raster resolution,
connected-object semantics and Shapefile format limits still apply.
